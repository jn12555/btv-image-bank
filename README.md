# Village image collection

Password-protected working version of a collection of photographs of rural villages. The gallery page is encrypted (AES-256-GCM); only ciphertext of the page is stored in this repository.

The photographs in images/ and thumbs/ come from Wikimedia Commons. Each image remains under its own licence (public domain, CC0, CC BY or CC BY-SA); no licence is granted by this repository. Each village folder holds a CREDITS.txt with the attribution required for CC BY and CC BY-SA images.
